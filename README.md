# ipea-emendas-subnacional
Pipeline em Python e modelo econométrico em painel de Efeitos Fixos (Two-Way Fixed Effects) com microdados do Portal da Transparência e Siconfi/Tesouro Nacional (2021–2024), avaliando o impacto das emendas parlamentares federais no esforço fiscal e na arrecadação própria (IPTU e ISS) dos municípios brasileiros.
